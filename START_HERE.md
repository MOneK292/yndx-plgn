# 🚀 Начните здесь!

## Что это?

Расширение для Chrome, которое улучшает работу с заданиями на Яндекс.Картах.

## Быстрый старт

### Вариант 1: Автоматическое развертывание (Windows)

1. Дважды кликните на `QUICK_DEPLOY.bat`
2. Дождитесь завершения
3. Откройте https://github.com/MOneK292/yndx-plgn

### Вариант 2: Ручное развертывание

Откройте терминал в папке проекта и выполните:

```bash
git init
git add .
git commit -m "Initial commit: Yandex Maps Task Manager Extension v1.5.0"
git remote add origin https://github.com/MOneK292/yndx-plgn.git
git branch -M main
git push -u origin main
```

## Что дальше?

### Установка расширения

1. Откройте Chrome
2. Перейдите в `chrome://extensions/`
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку проекта

### Использование

1. Откройте https://npro.maps.yandex.ru/
2. Расширение автоматически активируется
3. Счетчик задач появится в шапке

### Горячие клавиши

- `Alt + E` - Принять/Оценить
- `Alt + D` - Откатить/Забраковать
- `Alt + X` - Непрерывный режим
- `Alt + V` - MRC камера
- `Alt + B` - Панорама
- `Alt + N` - Обновить статистику
