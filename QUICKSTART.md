# Быстрый старт

## Установка

1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика"
3. "Загрузить распакованное расширение"
4. Выберите папку с проектом
5. Готово!

## Основные функции

### Горячие клавиши
- `Alt + E` → Принять/Оценить как верно
- `Alt + D` → Откатить/Забраковать
- `Alt + X` → Непрерывный режим
- `Alt + N` → Обновить статистику

### Автоматические функции
- Счетчик задач в header (зеленый/оранжевый)
- Расчет стоимости в рублях (желтым цветом)
- Кнопка 📋 для копирования адресов

## Проверка работы

Откройте консоль (F12) и найдите:
```
[Performance] ✅ Производительность в норме
[AddressCopy] ✅ Кнопка успешно добавлена
[Plugin] Статистика обновлена
```

## Если что-то не работает

1. Перезагрузите расширение
2. Обновите страницу (F5)
3. Проверьте консоль на ошибки
4. Убедитесь, что вы на npro.maps.yandex.ru

## Отключение логов (для production)

Если логи мешают, можно отключить performance-check.js:
1. Откройте `manifest.json`
2. Удалите `"performance-check.js"` из списка
3. Перезагрузите расширение

## Поддержка

Все логи начинаются с префиксов:
- `[Plugin]` - счетчик
- `[Hotkeys]` - клавиши
- `[AddressCopy]` - кнопки
- `[Performance]` - производительность

Скопируйте нужные логи при обращении за помощью.
