# Руководство по внесению вклада

Спасибо за интерес к проекту! Мы приветствуем любой вклад.

## Как внести вклад

### Сообщение об ошибках

1. Проверьте, не была ли уже создана похожая issue
2. Создайте новую issue с подробным описанием:
   - Шаги для воспроизведения
   - Ожидаемое поведение
   - Фактическое поведение
   - Скриншоты (если применимо)
   - Версия браузера и расширения

### Предложение новых функций

1. Создайте issue с описанием функции
2. Объясните, зачем она нужна
3. Дождитесь обсуждения перед началом разработки

### Pull Requests

1. Форкните репозиторий
2. Создайте ветку для вашей функции (`git checkout -b feature/amazing-feature`)
3. Внесите изменения
4. Убедитесь, что код работает
5. Закоммитьте изменения (`git commit -m 'Add amazing feature'`)
6. Запушьте в ветку (`git push origin feature/amazing-feature`)
7. Откройте Pull Request

## Стандарты кода

### JavaScript

- Используйте ES6+ синтаксис
- Добавляйте комментарии для сложной логики
- Используйте префиксы в console.log: `[ComponentName]`
- Следуйте существующему стилю кода

### Производительность

- Используйте throttling/debouncing для частых операций
- Минимизируйте использование MutationObserver
- Отключайте неиспользуемые observers
- Тестируйте влияние на производительность страницы

### Коммиты

Используйте понятные сообщения коммитов:
- `feat: добавлена новая функция`
- `fix: исправлена ошибка с...`
- `perf: улучшена производительность...`
- `docs: обновлена документация`
- `refactor: рефакторинг кода...`

## Тестирование

Перед отправкой PR убедитесь, что:
1. Расширение загружается без ошибок
2. Все функции работают корректно
3. Нет ошибок в консоли
4. Производительность страницы не ухудшилась

## Вопросы?

Создайте issue с вопросом или свяжитесь с автором.
