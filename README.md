# Yandex Maps Task Manager Extension

Расширение для браузера Chrome, которое улучшает работу с заданиями на платформе Яндекс.Карты (npro.maps.yandex.ru).

## 🚀 Основные возможности

### 1. Счетчик задач
- Отображение количества выполненных и ожидающих задач в шапке страницы
- Автоматическое обновление статистики
- Переключатель непрерывного режима работы (НВ)
- Возможность скрыть/показать счетчик

### 2. Расчет стоимости задач
Автоматически добавляет расчет в рублях рядом со статистикой:
- **Сообщения о неточностях:**
  - Сделано базовых: количество × 6₽
  - Выполнено проверок: количество × 6.5₽
- **Модерация:**
  - Сделано базовых: количество × 1.5₽
  - Выполнено проверок: количество × 3₽

### 3. Копирование адресов
- Кнопка 📋 рядом с каждым адресом для быстрого копирования
- Визуальная обратная связь при копировании (✓)
- Автоматическое появление кнопок при открытии новых заданий

### 4. Шаблоны сообщений для поддержки
Быстрые кнопки для вставки типовых сообщений:
- 🔖 **Закладка**: "Данную правку невозможно исправить с помощью Народной карты..."
- 🏠 **ФОС**: "Похоже, пользователь перепутал форму обратной связи..."

### 5. Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `Alt + E` | Принять правку (модерация) или Верно + Оценить (проверка) |
| `Alt + D` | Откатить правку (модерация) или Забраковать (проверка) |
| `Alt + X` | Переключить непрерывный режим |
| `Alt + V` | Открыть/закрыть MRC камеру |
| `Alt + B` | Открыть/закрыть панораму |
| `Alt + N` | Обновить статистику |

### 6. Автоматический перехват токенов
- Автоматическое сохранение CSRF токенов из HTTP запросов
- Не требует ручного ввода токена
- Работает в фоновом режиме

### 7. Мониторинг производительности
- Отслеживание нагрузки на страницу
- Автоматическая оптимизация работы observers
- Логирование в консоль при превышении нормы

## 📦 Установка

### Из исходников

1. Клонируйте репозиторий:
```bash
git clone https://github.com/MOneK292/yndx-plgn.git
cd yndx-plgn
```

2. Откройте Chrome и перейдите в `chrome://extensions/`

3. Включите "Режим разработчика" (Developer mode) в правом верхнем углу

4. Нажмите "Загрузить распакованное расширение" (Load unpacked)

5. Выберите папку с расширением

## 🎯 Использование

### Первый запуск

1. После установки откройте страницу https://npro.maps.yandex.ru/
2. Расширение автоматически перехватит токен авторизации
3. Счетчик задач появится в шапке страницы

### Управление плагином

Нажмите на иконку расширения в панели инструментов Chrome:
- **Получить статистику** - обновить данные вручную
- **Скрыть/Показать счетчик** - переключить видимость счетчика
- **Отключить/Включить плагин** - полностью отключить все функции

### Если плагин тормозит страницу

1. Откройте popup расширения
2. Нажмите "Отключить плагин"
3. Перезагрузите страницу
4. Включите обратно когда нужно

## 🛠️ Технические детали

### Структура проекта

```
yndx-plgn/
├── manifest.json                    # Конфигурация расширения
├── popup.html                       # Интерфейс popup
├── popup.js                         # Логика popup
├── background.js                    # Фоновый скрипт (перехват токенов)
├── content-script.js                # Основной скрипт (счетчик задач)
├── stats-enhancer.js                # Расчет стоимости
├── address-copy-button.js           # Кнопки копирования адресов
├── support-message-buttons.js       # Шаблоны сообщений
├── hotkeys.js                       # Горячие клавиши
├── token-finder-inpage.js           # Перехват токенов (inpage)
├── performance-check.js             # Мониторинг производительности
└── icons/                           # Иконки расширения
```

### Оптимизация производительности

Расширение использует:
- **Throttling/Debouncing** для всех MutationObserver (1-3 сек)
- **Автоотключение** observers через 30 секунд
- **Фильтрацию** нерелевантных изменений DOM
- **Отложенную загрузку** (`document_idle`)
- **Периодическую очистку** кеша (каждые 5 минут)

Типичная нагрузка: < 2% CPU, ~5-10 MB RAM

## 🔧 Разработка

### Требования

- Google Chrome 88+
- Manifest V3

### Отладка

1. Откройте `chrome://extensions/`
2. Найдите расширение и нажмите "Подробнее"
3. Нажмите "Проверить представления: service worker" для отладки background.js
4. Откройте DevTools на странице npro.maps.yandex.ru для отладки content scripts

### Логирование

Все компоненты используют префиксы в логах:
- `[Plugin]` - основной счетчик
- `[StatsEnhancer]` - расчет стоимости
- `[AddressCopy]` - копирование адресов
- `[SupportButtons]` - шаблоны сообщений
- `[Hotkeys]` - горячие клавиши
- `[TokenFinder]` - перехват токенов
- `[Performance]` - мониторинг производительности
