# Yandex Maps Task Manager Extension

Облегченное расширение для браузера Chrome, которое ускоряет работу с заданиями на платформе Яндекс.Карты (npro.maps.yandex.ru).

## 🚀 Основные возможности

### 1. Быстрые клавиши

| Комбинация | Действие |
|------------|----------|
| `Alt + E` | Принять правку (модерация) или Верно + Оценить (проверка) |
| `Alt + D` | Откатить правку (модерация) или Забраковать (проверка) |
| `Alt + X` | Переключить непрерывный режим (НВ) |
| `Alt + V` | Открыть/закрыть MRC камеру |
| `Alt + B` | Открыть/закрыть панораму |
| `Alt + N` | Пересчитать стоимость заданий |

### 2. Подсчет стоимости задач
Автоматически добавляет расчет в рублях рядом со статистикой и общую сумму в Диспетчере задач:
- **Сообщения о неточностях:**
  - Сделано базовых: количество × 6₽
  - Выполнено проверок: количество × 6.5₽
- **Модерация:**
  - Сделано базовых: количество × 1.5₽
  - Выполнено проверок: количество × 3₽

### 3. Кнопки копирования
- Кнопка 📋 рядом с именованными объектами и адресами для быстрого копирования
- Отдельная кнопка 📋 рядом с номером дома для копирования полного адреса в формате `Улица, Номер дома`
- Визуальная обратная связь при копировании (✓)
- Исключение безымянных маневров и связей

### 4. Кнопки вставки шаблонов поддержки
Быстрые кнопки для вставки типовых сообщений в форму обращения:
- 🔖 **Закладка**: "Данную правку невозможно исправить с помощью Народной карты..."
- 🏠 **ФОС**: "Похоже, пользователь перепутал форму обратной связи..."

## 📦 Установка

### Из исходников

1. Клонируйте репозиторий:
```bash
git clone https://github.com/MOneK292/yndx-plgn.git
cd yndx-plgn
```

2. Откройте Chrome и перейдите в `chrome://extensions/`

3. Включите "Режим разработчика" (Developer mode) в правом верхнем углу

4. Нажмите "Загрузить распакованное расширение" (Load unpacked)

5. Выберите папку с расширением
