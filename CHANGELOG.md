# История изменений

## [1.5.0] - 2024-12 (Подготовка к GitHub)

### Добавлено
- Полная документация проекта (README.md, CONTRIBUTING.md, DEPLOY.md, GITHUB_SETUP.md)
- Файлы для GitHub (.gitignore, LICENSE, .env.example)
- Подробное описание всех функций в README
- Инструкции по развертыванию и обновлению

### Изменено
- Увеличены интервалы throttling для снижения нагрузки:
  - stats-enhancer.js: 100мс → 3 сек
  - address-copy-button.js: 300мс → 1 сек, периодическая проверка 2с → 2.5с
  - content-script.js: 100мс → 2 сек, debounce 3с → 5с
- Ускорена работа кнопок копирования адресов (в 2 раза)
- Улучшена работа шаблонов сообщений с периодической проверкой (каждые 3 сек)
- Observer для шаблонов отключается через 30 сек (было 20)

### Удалено
- Неиспользуемый файл cloneToggleControl.js
- Файл с логами destraction.html

### Исправлено
- Проблема с исчезновением кнопок шаблонов после отключения observer
- Избыточные пустые строки в коде
- Проблемы с кодировкой UTF-8 в русских комментариях

## [1.3.0] - 2024 (Оптимизация производительности)

### Добавлено
- Мониторинг производительности (performance-check.js)
- Автоматическое отключение MutationObserver'ов
- Throttling для всех Observer'ов
- README.md с документацией
- OPTIMIZATION.md с рекомендациями

### Оптимизировано
- address-copy-button.js: throttling 1 сек, отключение через 10 сек
- stats-enhancer.js: throttling 2 сек, отключение через 15 сек
- support-message-buttons.js: throttling 1 сек, отключение через 20 сек
- content-script.js: throttling 2 сек для URL observer

### Исправлено
- Конфликт имен переменных (observer → addressCopyObserver)
- Избыточные срабатывания MutationObserver (с 600 до <50 за 5 сек)
- Лаги браузера из-за частых проверок DOM
