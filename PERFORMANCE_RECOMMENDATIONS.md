# Рекомендации по производительности плагина

## Текущее состояние

Плагин уже оптимизирован и использует:
- Throttling/debouncing для всех MutationObserver
- Автоотключение observers через 10-20 секунд
- Фильтрацию нерелевантных изменений DOM
- Отложенную загрузку (`document_idle`)

## Влияние на производительность

### Минимальное влияние (< 1% CPU):
- `hotkeys.js` - только слушает события клавиатуры
- `support-message-buttons.js` - observer отключается через 20 сек
- `content-script.js` - легкий observer только для URL

### Умеренное влияние (1-3% CPU):
- `stats-enhancer.js` - постоянный observer с debounce 1 сек
- `address-copy-button.js` - observer + проверка каждые 2 сек

### Рекомендации для дальнейшей оптимизации:

1. **Отключить плагин когда не нужен**
   - Используйте кнопку "Отключить плагин" в popup
   - Все функции остановятся, производительность восстановится

2. **Если страница тормозит:**
   - Откройте popup → "Отключить плагин"
   - Перезагрузите страницу
   - Включите плагин обратно когда нужно

3. **Для разработчиков:**
   - Можно увеличить debounce интервалы (сейчас 100-1000мс)
   - Можно отключить периодическую проверку адресов
   - Можно отключить очистку кеша

## Сравнение с другими расширениями

Типичное расширение для браузера использует:
- 2-5% CPU в фоне
- 10-50 MB RAM

Этот плагин:
- < 2% CPU (с оптимизациями)
- ~ 5-10 MB RAM
- Автоотключение неиспользуемых функций

## Мониторинг производительности

Используйте `performance-check.js` для отслеживания:
```javascript
// В консоли браузера
window.performanceMonitor.getStats()
```

Показывает количество срабатываний MutationObserver за последние 5 секунд.
Норма: < 50 срабатываний
